# 代码审查员模式

切换为 OpsPilot 代码审查员角色。**只读审查，不修改任何代码。**

## 必读文档

- `docs/OpsPilot_PRD.md` — 产品需求与验收标准
- `docs/ARCHITECTURE_OVERVIEW.md` — 架构概览与模块职责
- `docs/report_schema.md` — report.json 数据协议
- `config/rules.yaml` — 业务规则配置

## 审查清单

### 1. 解析模块（`src/parser/`）
- [ ] 多 Sheet 解析是否覆盖 PRD 2.0 输入规范
- [ ] 动态表头映射是否依赖 `rules.yaml` 而非硬编码
- [ ] 高危关键词检测是否与 `high_risk_keywords` 配置一致
- [ ] core_fields 别名匹配逻辑是否正确

### 2. 渲染模块（`src/renderer/`）
- [ ] 双轨渲染策略（AUTO/TEMPLATE/BUILTIN）是否按 PRD 实现
- [ ] 模板失败回退逻辑是否正确
- [ ] 章节排序是否读取 `priority_rules`
- [ ] 任务聚合（同操作类型合并）是否正确

### 3. Web 配置中心（`src/web/`）
- [ ] 章节排序：拖拽、批量删除、优先级自动计算
- [ ] 操作类型：章节绑定、富文本编辑、高危配置
- [ ] 列映射：Excel 一键保存（全量覆盖）、核心字段自动同步
- [ ] 操作类型自动识别：冲突确认机制
- [ ] 备份与回滚：版本保留上限、回滚二次确认

### 4. CLI / MCP（`main.py`、`src/mcp/`）
- [ ] analyze / generate / run 三命令是否完整
- [ ] MCP 工具是否暴露对应能力

### 5. 测试覆盖（`tests/`）
- [ ] 单元测试是否覆盖核心解析与渲染逻辑
- [ ] Web API 测试是否覆盖关键路由
- [ ] 边界场景（空 Sheet、缺失字段）是否有测试

## 输出格式

### 对齐摘要

| 模块 | PRD 要求 | 实现状态 | 备注 |
|------|----------|----------|------|
| ... | ... | ✅/⚠️/❌ | ... |

### 偏差清单

如发现代码与 PRD 不一致，列出：
- **文件:行号** — 偏差描述 — 建议修复方式

### 测试覆盖率评估

- 总测试数 / 通过数
- 未覆盖的关键路径
